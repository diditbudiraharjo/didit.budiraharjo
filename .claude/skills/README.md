# Skills

Skills installed from [ComposioHQ/awesome-claude-skills](https://github.com/ComposioHQ/awesome-claude-skills) (Apache-2.0, see upstream repo for individual skill licenses — some carry a separate proprietary license per their own `LICENSE.txt`).

Not included from that repo:
- `connect-apps-plugin/` — a Claude Code plugin (not a skill) that requires a Composio API key to connect Claude to 1000+ external apps. Install separately with `claude --plugin-dir` if needed; see the upstream README.
- `composio-skills/` — ~830 per-app automation skills (Slack, Adobe, etc.) generated from Composio's app catalog. Each requires the Composio connection to be configured. Skipped due to volume/setup requirements; pull individual ones from upstream if needed.
