# Design Skills

67 design-system skills installed from [bergside/awesome-design-skills](https://github.com/bergside/awesome-design-skills) (MIT licensed).

Each subfolder is a self-contained Claude Code skill:
- `SKILL.md` — AI-agent instructions (tokens, component rules, accessibility constraints)
- `DESIGN.md` — human-readable design intent and rationale

Claude Code will automatically pick the matching skill (e.g. `brutalism`, `glassmorphism`, `minimal`) based on the design aesthetic requested in a task.
