# n8n skills

The `n8n-*` and `using-n8n-mcp-skills` folders here are copied from
[czlonkowski/n8n-skills](https://github.com/czlonkowski/n8n-skills) (MIT
licensed, see `THIRD_PARTY_LICENSE-n8n-skills.txt`). They give Claude Code
expert guidance for building n8n workflows: expression syntax, workflow
patterns, validation, node configuration, JavaScript/Python code nodes,
error handling, binary data, sub-workflows, agents, multi-instance
targeting, and self-hosting.

They activate automatically on relevant n8n tasks. Full tool support
(workflow creation/validation via the `n8n-mcp` MCP server) requires
configuring an `n8n-mcp` entry in `.mcp.json` with your n8n instance URL
and API key — see the upstream repo's `docs/INSTALLATION.md` for details.
