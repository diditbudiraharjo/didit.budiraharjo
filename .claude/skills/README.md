# Skills

Installed from [emilkowalski/skills](https://github.com/emilkowalski/skills) (MIT licensed, © Emil Kowalski).

Design-engineering skills covering animation, UI polish, and interface decisions:

- **emil-design-eng** — Main skill: animation and design advice philosophy.
- **review-animations** — Strict animation review against a fixed rule set.
- **improve-animations** — Audit animations in a codebase and produce prioritized fix plans.
- **find-animation-opportunities** — Find UI spots that would benefit from motion (and what not to animate).
- **animation-vocabulary** — Vocabulary for describing the animation you want.
- **apple-design** — Apple's interface design and motion principles, adapted for the web.
- **pick-ui-library** — Pick a trusted UI library instead of hand-rolling or grabbing an abandoned package.
- **prototype** — Build multiple UI variations and switch between them.
